# Contributing

Work on a feature branch. Keep the compaction path deterministic at its
boundaries: every source must be covered exactly once, foreground review must
never wait for a proposal model, and cancellation must never allow the original
compaction to proceed silently.

Before opening a pull request:

```bash
python3 -W error::ResourceWarning -m unittest discover -s tests -v
python3 -m py_compile compact-focus/compact_focus/*.py
claude plugin validate . --strict
git diff --check
```

For hook or terminal changes, also run a fresh `claude --plugin-dir
./compact-focus` session and exercise one bare `/compact`. Do not commit local
state, transcripts, media payloads, plugin caches, or generated bytecode.

Bug reports should include Claude Code and Python versions, operating system,
whether the proposal was deterministic/hybrid/Claude-generated, and the
relevant event names from `compact-focus status --json`. Redact transcript text
before sharing state artifacts.
